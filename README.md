# Imran Khan I – React Portfolio

```bash
npm install
npm run dev      # local dev server
npm run build    # production build in /dist
```

- Edit your content in `src/data.js` (skills, jobs, projects, FORM_ENDPOINT).
- Colors and design tokens are at the top of `src/styles.css`.
- Add a photo: put `profile.jpg` in `public/` and use it inside `.photo` in `src/App.jsx`.
